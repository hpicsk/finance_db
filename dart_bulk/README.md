# dart_bulk — 전 상장사 재무제표, OpenDART 일괄다운로드 아카이브

`https://opendart.fss.or.kr/disclosureinfo/fnltt/dwld` 가 (사업연도·보고서·재무제표)
마다 하나씩 내는 zip 을 그대로 보관하고, **어느 빈티지를 읽을지**를 정한다.
항목코드를 무슨 계정으로 읽을지는 여기서 정하지 않는다 — 그것은 소비자의 방법론이다.

## 왜 기업별 API 가 아니라 이것인가

| | 기업별 `fnlttSinglAcntAll` | 일괄다운로드 |
|---|---|---|
| 300종목 × 11년 | 약 3,300 콜 | **33 요청** |
| 한도 | 일 20,000, 초과 시 IP 차단(리다이렉트 후 TLS 끊김) | 걸릴 수 없음 |
| 내용 | 같음 | 같음 |

같다는 것은 확인된 사실이다: `OpenDartReader.finstate_all()` 은 같은 엔드포인트를
부르고, 코스맥스·셀트리온 FY2025 에서 일괄 zip 과 **동일한 행**을 돌려준다
(40/42 BS 행, 같은 태그, 같은 금액). 라이브러리를 바꿔서 메울 수 있는 결측이
아니라는 뜻이다 — 어떤 발행사는 차입금 줄 자체를 재무제표에 안 적고 주석에만 적는다.

## 지금 디스크에 있는 것

측정해서 본다. 선언한 표는 조용히 낡는다.

```python
import dart_bulk
print(dart_bulk.coverage())      # 행 (연도·보고서), 열 재무제표, 값 빈티지 생성시각
```

2026-08-25 기준: **FY2015–2025** 와 **분기(FQ·HY·TQ) 2016–2024** 가 BS·PL·CF 전부,
그 밖에 2025 HY(BS·PL — CF 없음) 와 2026 FQ·HY. zip 138개.

비어 있는 칸은 "안 받음"이지 "발행처가 안 냄"이 아니다. 둘을 가르려면
`download.catalog()` 로 사이트가 지금 제공하는 목록을 받아 이 표와 대조한다.
대조하면 나오는 실제 사례가 **2015 분기**다 — 목록에 없다. 안 받은 것이 아니라
일괄다운로드가 2016 부터인 것이고, 개별 공시에는 있으므로 필요하면 기업별 API 로
받아야 한다(= 위 표의 콜 수로 돌아간다).

## 빈티지가 이 패키지의 전부다

FSS 는 제출이 들어오는 대로 일괄파일을 다시 만들고 **옛 파일을 지우지 않는다.**
새 파일은 이름 끝 14자리 생성시각만 바뀐다.

- 전부 읽으면 옛 스냅샷이 중복 제거에서 이긴다. 안정 정렬이라 동점이 읽은 순서로
  풀리기 때문이고, 우연이 아니라 **항상 그 방향**이다.
- 그래서 `latest_vintages()` 가 14자리를 명시적으로 뽑아 고른다. 사전순이 마침
  시각순인 것에 기대지 않는다.
- 이름이 규칙에 안 맞으면 **멈춘다.** 못 읽은 이름은 "빈티지 0"이 아니라 "빈티지
  모름"이고, 기본값을 주는 순간 그 파일이 조용히 가장 낡은 것이 되어 정렬에서 진다.
- 옛 빈티지로 결측을 메우지 않는다. 폐기된 값과 현재 값을 한 행에 섞으면 **어느
  시점에도 존재한 적 없는 행**이 된다.

`download` 는 받은 뒤 밀려난 빈티지를 지우고, 지운 이름을 `bulk_vintage_pruned.csv`
에 덧붙인다. 지우기만 하면 그 파일이 있었다는 사실이 사라지고, 소비자 쪽 사이드카의
`superseded` 열은 늘 비어 "재생성된 적 없음"으로 읽힌다 — 지운 것과 없던 것이 같은
빈칸이 된다.

## 읽기

```python
from dart_bulk import latest_vintages, open_zip, sheets

for p in latest_vintages("*_4Q_PL_*.zip"):      # (연도·분기·재무제표)당 최신 한 벌
    with open_zip(p) as zf:
        for info, name, consolidated in sheets(zf):
            ...          # CP949 · 탭 구분 · 항목코드/항목명/당기/전기
```

형식(FY2024 파일에서 확인, 추측 아님): CP949, 탭 구분, 헤더 한 줄.

```
재무제표종류 종목코드 회사명 시장구분 업종 업종명 결산월 결산기준일
보고서종류 통화 항목코드 항목명 당기 전기 전전기
```

반기 파일의 금액 컬럼명은 연간과 **다르다**(`당기 반기 누적` 등). 컬럼 이름을
연간에서 외워 쓰면 반기에서 빈 표가 나온다.

`sheets()` 는 기본으로 금융업(금융기타·보험·은행·증권) 시트를 뺀다. 계정 체계가
달라 같은 항목코드가 다른 것을 뜻하기 때문이고, 필요하면 `skip_sectors=()` 로 연다.
연결/별도는 엔트리 이름으로 갈리며, 어느 쪽을 쓸지는 부르는 쪽이 정한다.

## 이 패키지가 하지 않는 것

- **항목코드 → 필드 매핑.** 어떤 태그를 `revenue` 로 읽을지는 방법론이다. 발행사
  확장태그·표제 불일치·연결 우선순위 같은 선택이 전부 거기 붙는다.
- **패널 조립과 그 사이드카.** 어느 빈티지로 패널을 만들었는지는 그 패널을 만든
  저장소가 자기 옆에 적는다(`bulk_vintage.csv`). 재생성하면 오늘의 아카이브가 되므로,
  지난달 점수가 어느 빈티지였는지는 그때 커밋된 사이드카에만 남는다.
- **주석(주기) 파싱.** 재무제표 본문에 없는 항목 — 예: 차입금 줄을 안 적고 금융부채
  집계만 적는 발행사 — 은 `dart.document(rcept_no)` + 표 파싱이 필요하고, 이 아카이브에
  없다.

## 갱신

```bash
python -m dart_bulk.download --list                                   # 사이트 목록만
python -m dart_bulk.download --years 2015-2025 --reports FY           # 연간
python -m dart_bulk.download --years 2016-2025 --reports FQ,HY,TQ     # 분기 (미수집)
```

주기: 사업보고서 시즌(3~4월) 이후와, 개정이 반영됐는지 확인하고 싶을 때. 다시
받아도 같은 파일이면 캐시로 건너뛰고, 새 빈티지가 있으면 받은 뒤 옛 것을 지운다.
